Tacit Collusion in LLM Bidders

Oct 2026 · github.com/linusc9516/bid-pricing-collusion

190 sessions · 3 models · ~$6

  • Ran 190 sessions across 3 models and 3 tie-break rules for about $6, with a deterministic auctioneer and a matched one-shot control for every condition.
  • Found no tacit rotation at 5 sessions per condition. Ties occurred in 3.07% of rounds against 0.03% by chance, and one two-bidder session held bids at 94–96 from round 10, so I flagged it for follow-up.
  • Measured collusion with an index normalised to the Bayes-Nash benchmark (0 competitive, 1 at the reserve price), using the session as the unit and pre-specified Holm-corrected comparisons, so overbidding is not mistaken for coordination.
  • Added a pytest suite, log validation, resumable runs and a viewer that shows each session beside its control.
  • Python
  • pytest
